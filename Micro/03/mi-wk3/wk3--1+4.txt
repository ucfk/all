ORG  0000H  
    MOV  DPTR, #9000H ; กำหนดตำแหน่งเริ่มต้นใน External RAM
    MOV  A, #00H      ; กำหนดค่าเริ่มต้นที่จะเติมคือ 00H

LOOP:  
    MOVX @DPTR, A     ; นำค่าใน A (เริ่มที่ 00) ไปเขียนลงแรมที่ตำแหน่ง DPTR
    INC  A            ; เพิ่มค่าที่จะเติมขึ้น 1 สำหรับรอบถัดไป
    INC  DPTR         ; เลื่อนตำแหน่งแรมไปช่องถัดไป
    
    ; เช็คเงื่อนไขหยุด: 
    ; เราต้องการทำถึง 90FFH ดังนั้นลูปจะหยุดเมื่อ DPTR เลื่อนไปถึง 9100H
    ; วิธีเช็ค DPTR 16 บิตที่ง่ายที่สุดคือเช็คตัวคูณที่ทำให้ครบรอบ (ในที่นี้คือ 256 ครั้ง)
    ; หรือเช็คค่า A ถ้าเติม 00 ถึง FF ครบแล้ว รอบถัดไป A จะวนกลับมาเป็น 00 พอดี
    
    JNB  ACC.7, CONTINUE ; (เทคนิคพิเศษ) ถ้ายังเติมไม่ครบ ให้ทำต่อ
    ; หรือใช้วิธีมาตรฐานคือเช็คว่า A กลับมาเป็น 0 หรือยัง
    CJNE A, #00H, LOOP  

    JMP  $  
    END
